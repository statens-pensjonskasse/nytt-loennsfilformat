# Hele innsendingen avvises

En innsending som ikke følger skjemaet, avvises i sin helhet, og ingen personer behandles. Den rettede innsendingen sendes med ny innsendingsId.

- `1_sluttaarsak_uten_sluttdato`: En periode har sluttårsak uten sluttdato, og innsendingen følger derfor ikke skjemaet (SKJEMA_DEPENDENT_REQUIRED). Filen er med vilje ugyldig.
- `2_rettet`: Den rettede innsendingen sendes på nytt med ny innsendingsId.
